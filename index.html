نبذة عني

أنا مبرمج ومتخصص في مجال تقنية المعلومات (IT). أمتلك شغفاً كبيراً بالبرمجة وحل المشكلات وتطوير الأنظمة المتقدمة. قمت بدراسة وتطبيق تقنيات تطوير الويب وتطبيقات الهواتف والأنظمة الحديثة لبناء تطبيقات متكاملة وقوية، وأسعى دائماً لتوظيف التكنولوجيا في بناء حلول ذكية ومبتكرة لخدمة سوق العمل.

مهاراتي البرمجية

HTML5 CSS3 / Tailwind JavaScript TypeScript React Native Node.js & Express PHP / Laravel MySQL / Drizzle ORM C# C++

نظام صيدلية حديث (Pharmacy System)
