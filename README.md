# 🌐 معرض الأعمال الشخصي | Portfolio Website

مرحباً بك في مستودع معرض الأعمال الشخصي الخاص بي (محمد الطيب). يعرض هذا الموقع مهاراتي البرمجية المتقدمة، مشاريعي الحديثة في تطوير الويب وتطبيقات الهواتف، وطرق التواصل معي.

---

## 🌟 المميزات (Features)

* **تصميم عصري وجذاب:** واجهة مستخدم متناسقة تعتمد على الألوان الداكنة (Dark Theme) المريحة للعين والمخصصة للمطورين.
* **تجاوب كامل (Responsive Design):** متوافق كلياً مع مختلف أجهزة الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.
* **تفاعل سلس:** تمرير سلس (Smooth Scrolling) بين أقسام الصفحة عبر القائمة الرئيسية.
* **دعم اللغة العربية (RTL):** محاذاة وتنسيقات مهيأة خصيصاً للغة العربية.
* **تحسينات احترافية:** رسالة ترحيبية تفاعلية في كونسول المتصفح (Browser Console).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), React, TypeScript, Tailwind CSS
* **Backend & Databases:** Node.js (Express), Drizzle ORM, PHP, MySQL, XAMPP
* **Mobile Development:** React Native, Expo
* **Tools & Utilities:** Font Awesome, Git, GitHub, VS Code

---

## 🚀 أبرز المشاريع المعروضة (Featured Projects)

1. **نظام صيدلية حديث (Pharmacy System):** تطبيق إدارة ونقاط بيع مباشرة مبني بأحدث التقنيات (React, TypeScript, Node.js, Express, Drizzle ORM, MySQL).
2. **Nawa — صفحة هبوط عربية:** صفحة هبوط تفاعلية بتصميم RTL أنيق مصممة بـ Tailwind CSS وHTML5 مع خادم معاينة خفيف بـ Node.js.
3. **تطبيق طيبُ الأثر (Tayyib Al-Athar):** تطبيق هاتف ذكي متكامل باستخدام React Native و Expo و TypeScript.
4. **نظام إدارة البيانات المتكامل:** موقع ويب ديناميكي لإدارة واستخراج البيانات وحفظها باستخدام PHP و MySQL.
5. **برنامج إدارة الخوارزميات والذاكرة:** تطبيق متقدم بلغة C++ يوضح مهارات هيكلة البيانات وإدارة الذاكرة.
