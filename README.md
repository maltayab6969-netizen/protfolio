# 🌐 معرض الأعمال الشخصي | Portfolio Website

مرحباً بك! هذا الموديل يمثل موقع معرض الأعمال الشخصي (Portfolio) الخاص بي، والذي يعرض مهاراتي البرمجية، المشاريع التي قمت بتطويرها، وطرق التواصل معي.

---

## 🌟 المميزات (Features)

* **تصميم عصري وجذاب:** واجهة مستخدم متناسقة تعتمد على الألوان الداكنة (Dark Theme) المريحة للعين.
* **تجاوب كامل (Responsive Design):** متوافق كلياً مع مختلف أجهزة الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة.
* **تفاعل سلس:** تمرير سلس (Smooth Scrolling) بين أقسام الصفحة عبر القائمة الرئيسية.
* **دعم اللغة العربية (RTL):** محاذات وتنسيقات مهيأة خصيصاً للغة العربية.
* **تحسينات احترافية:** رسالة ترحيبية وتفاعلية في كونسول المتصفح (Browser Console).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **HTML5:** لبناء هيكل الصفحة وإتاحة عناصر سيمانتيك (Semantic HTML).
* **CSS3:** لتنسيق الواجهة، واستخدام Flexbox & Grid، والتقنيات العصرية مثل `backdrop-filter`.
* **JavaScript (Vanilla JS):** لإضافة التفاعلية للروابط والتنبيهات المخصصة.
* **Font Awesome:** لإدراج الأيقونات التفاعلية البصرية.
